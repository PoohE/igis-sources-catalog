# IGIS Sources Catalog — система каталогизации историко-географических источников

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22729475.svg)](https://doi.org/10.5281/zenodo.22729475)

**Каталогизация и описание характеристик содержания историко-географических картографических,
текстовых и статистических источников федеральных и региональных архивов России для построения
исторических геоинформационных систем (ИГИС).**

Единица каталога описывается **74 полями в четырёх блоках** — от идентификационных атрибутов до
**аналитического паспорта** источника (применимые методы пространственного анализа, возможность и
точность геопривязки, совместимость с другими источниками). Классификация охватывает **24 типа
источников трёх классов** (картографические A1–A6, текстовые B1–B10, статистические серийные
C1–C8). Структура гармонизирована со стандартами **ISAD(G), MARC 21, Dublin Core, ISO 19115**.

📄 **Основной документ:** [catalog_guidelines_ru.md](catalog_guidelines_ru.md) — руководство
v1.5 (сентябрь 2026): система полей (включая поле 14а «Год сведений» — датировка состояния
местности, отличаемая от даты издания), классификация, справочники, маппинг стандартов,
рабочий процесс, приложения; **таблица 10а** — статус автоматизированного сбора по 26
архивно-библиотечным системам (аудит 2026-09-13).

## Назначение

- унифицированное описание источников XVII — начала XX века из архивов и библиотек России;
- перенос акцента каталогизации с хранения на **аналитическое переиспользование**: паспорт
  фиксирует информационный потенциал документа и делает предварительную оценку переносимой
  между проектами;
- основа иерархических исторических ГИС уровня «губерния — уезд — волость».
